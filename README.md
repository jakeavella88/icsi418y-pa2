Signup/Login Interface
This application is a demonstration of how React and Express interact with each other. The client side utilizes React to gather user information for account creation or log in, then communicates with the Express backend server using HTTP requests, which validates the input fields are filled out, and either creates an entity in MongoDB or looks for the matching credentials. The server then sends back the corresponding message to determine whether the request was successful or not, and that message gets displayed.
